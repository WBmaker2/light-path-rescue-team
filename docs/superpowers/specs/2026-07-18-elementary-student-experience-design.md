# 빛길 구조대 초등학생 경험 개선 설계

- 승인일: 2026-07-18
- 승인안: A안 · 전체 학생 경험 개선
- 근거 문서: `docs/2026-07-18-elementary-student-usability-audit.md`

## 목표

초등학교 5~6학년 학생이 `예상 → 선택 → 그림 관찰 → 설명 → 수정` 흐름을 혼자 따라갈 수 있게 한다. 과학 용어는 없애지 않고 짧은 뜻풀이를 제공하며, 학생의 선택 결과가 작은 화면에서도 반드시 눈에 보이도록 한다.

## 유지할 원칙

- 안내 활동 1개와 본 미션 5개의 순서와 과학적 범위는 유지한다.
- 점수, 로그인, 영구 저장, 드래그 조작은 추가하지 않는다.
- 빛길 그림과 글로 된 빛길 순서는 같은 `TraceResult`를 사용한다.
- 거울·렌즈 실제 실험의 안전 안내를 유지한다.
- 모든 조작은 키보드와 44px 이상의 터치 목표로 사용할 수 있어야 한다.
- 코드 파일은 500줄을 넘기지 않는다.

## 1. 다시 시작 동작

결과 화면과 헤더의 다시 시작은 같은 완전 초기화 동작을 사용한다.

완전 초기화 대상:

- 현재 화면과 미션 번호
- 예상, 장치 선택, 첫 장치 선택
- 빛길 결과와 현재 공개 구간
- 확인 횟수와 설명 선택
- 피드백과 미션별 관찰 기록
- 헤더의 완료 미션 수

결과 화면은 이미 활동을 마친 상태이므로 별도 확인 없이 완전 초기화한다. 헤더의 `처음부터`는 진행 중 기록 손실을 막기 위해 기존 확인 대화상자를 유지한다.

## 2. 작은 화면 관찰 동선

820px 이하 화면에서 `빛길 확인`을 누르면 결과가 반영된 `빛길 그림`으로 이동한다.

- 그림 카드가 프로그램 초점을 받아 화면 읽기 도구에도 새 결과가 알려진다.
- 동작 줄이기 설정에서는 즉시 이동하고, 그 외에는 부드럽게 이동한다.
- 그림 아래에 `빛길 기록으로 가기` 링크를 표시한다.
- 링크는 아래의 `빛길 순서` 제목으로 이동한다.
- 데스크톱에서는 현재 두 열 배치를 유지하고 자동 이동하지 않는다.

## 3. 마지막 종합 미션

미션 5의 장치 카드는 확인 전 정답을 숨긴다.

- 확인 전: 장치 이름과 `역할은 확인 뒤 공개` 표시
- `모두 거울` 선택 후: 세 장치에 거울 역할 표시
- `모두 렌즈` 선택 후: 세 장치에 렌즈 역할 표시
- 정답 선택 후: 잠망경은 평면거울·반사, 돋보기와 카메라는 볼록렌즈·굴절 표시

정답 결과의 빛길 순서는 세 관계를 모두 제공한다.

1. 잠망경 → 평면거울 → 반사
2. 돋보기 → 볼록렌즈 → 굴절
3. 카메라 → 볼록렌즈 → 굴절

## 4. 학생용 문장

### 공통 문구

| 기존 | 변경 |
| --- | --- |
| 가상 경로 | 화면 속 빛길 |
| 근거로 고쳐 보기 | 본 것을 보고 고쳐 보기 |
| 가상 빛줄기 | 화면 속 빛줄기 |
| 제한된 모형 | 이 화면에서 보여 주는 범위 |
| 검수된 선택지 | 준비된 보기 |
| 가상 빛길 작업대 | 빛길 그림 |
| 관찰 기록 · 텍스트 경로표 | 빛길 순서 |
| 한 단계씩 | 다음 빛길 보기 |
| 관찰 근거로 설명하기 | 본 것을 바탕으로 설명하기 |
| 세 장치 결합 연결 | 세 장치의 역할 고르기 |

### 설명 단계

조사 결합으로 문장을 만들지 않는다. 모든 미션에서 다음 고정 안내를 사용한다.

1. 그림에서 빛이 멈추거나 방향을 바꾼 곳을 찾아요.
2. 빛길 순서를 읽어요.
3. 알맞은 설명을 골라요.

미션별 핵심 용어는 별도 풀이로 제공한다.

- 직진: 같은 물질 속에서 빛이 곧게 나아가는 것
- 반사: 거울에서 빛의 방향이 바뀌는 것
- 굴절: 렌즈를 지나며 빛의 방향이 바뀌는 것
- 초점: 빛이 한곳에 모이는 곳
- 장치 쓰임: 장치가 거울이나 렌즈의 성질을 이용하는 방법

### 장면 도움말

단순히 `장면에서 찾아봐요`를 반복하지 않고 미션마다 관찰할 내용을 알려 준다.

- 안내: 빛이 시작하는 곳, 빛이 닿아야 보이는 물체, 빛이 이어지는 마지막 곳
- 직진: 두 구멍이 같은 높이인지 비교
- 거울 1개: 빛이 닿을 거울 자리와 기울기 비교
- 거울 2개: 첫 번째와 두 번째로 방향이 바뀌는 자리 비교
- 렌즈: 세 빛줄기가 렌즈 뒤 어느 곳에서 모이는지 비교
- 장치: 세 장치의 이름을 확인하고 역할은 선택 뒤 확인

## 5. 진행 표시와 헤더

미션 화면에는 `전체 6단계 중 n단계` 진행 막대를 추가한다. 안내 활동도 첫 단계로 포함한다.

820px 이하에서는 헤더를 다음처럼 단순화한다.

- 브랜드와 본 미션 완료 수를 첫 줄에 표시
- `도움말` 메뉴 안에 `선생님용`, `모형과 안전`, `업데이트 내역` 배치
- `처음부터`는 별도 버튼으로 유지
- 업데이트 내역은 두 번 이하의 조작으로 열 수 있어야 한다.

## 6. 결과 화면

긴 3열 표를 미션별 카드 목록으로 바꾼다.

각 카드의 기본 내용:

- 활동 이름과 핵심 성질
- 처음 생각
- 마지막 선택
- 배운 점

`선택 기록 자세히 보기`를 펼치면 확인 횟수, 선택 수정 여부, 최종 설명을 볼 수 있다. 안내 활동은 기존처럼 결과 화면에서 제외한다.

## 7. 피드백

- 정답 설명: `맞아요. 그림에서 확인한 빛길과 잘 연결했어요.`
- 틀린 설명: 그림에서 멈추거나 바뀐 지점을 다시 읽도록 안내한다.
- 성공하지 못한 장면에서 정답 설명을 고르면 먼저 장치 선택을 수정하도록 안내한다.
- 실패 안내는 `막혔어요`로만 통일하지 않고 `표적과 다른 방향`, `거울 뒷면`, `초점 위치`를 구분한다.

## 8. 접근성과 반응형 기준

- 320px에서 가로 스크롤 없음
- 본문 16px 이상, 터치 목표 44px 이상
- 새 결과로 이동할 때 프로그램 초점이 보이며 스크린 리더 이름이 존재함
- 진행 막대는 `progressbar` 역할과 현재 단계 값을 제공함
- 도움말 메뉴와 모든 대화상자는 키보드로 열고 닫을 수 있음
- 동작 줄이기 설정에서 부드러운 스크롤을 사용하지 않음
- 심각 또는 치명적 axe 위반 없음

## 9. 업데이트 내역

다음 항목을 맨 위에 추가한다.

### 2026-07-18 · 학생 실사용 개선

다시 시작 오류를 고치고, 작은 화면에서도 선택 결과 그림을 바로 볼 수 있게 했어요. 어려운 문장과 결과 기록을 학생이 읽기 쉽게 다듬고 마지막 미션의 정답 미리 보기를 없앴어요.

## 10. 검증 시나리오

1. 결과 화면에서 다시 시작한 뒤 안내 활동에 이전 결과가 남지 않는다.
2. 320px에서 `빛길 확인` 뒤 그림 카드가 화면 안에 들어오고 초점을 받는다.
3. 미션 5는 확인 전 `반사`, `굴절` 정답을 보여 주지 않는다.
4. 미션 5 정답 결과는 세 장치 연결을 모두 보여 준다.
5. `직진와`, `굴절와`, `쓰임와`, `검수된`, `텍스트 경로표`가 화면에 없다.
6. 결과 화면에는 본 미션 카드 5개가 보이고 안내 활동은 제외된다.
7. 320px·768px·1280px에서 핵심 흐름을 완주할 수 있다.
8. 업데이트 내역에서 2026-07-18 항목을 확인할 수 있다.
