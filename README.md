# 빛길 구조대

초등 5~6학년 학생이 빛길을 먼저 예상하고, 가상 장면에서 직진·평면거울 반사·제한된 볼록렌즈 굴절을 관찰한 뒤 근거를 고르는 교육용 웹 앱입니다.

## 학습 흐름

안내 활동 1개와 본 미션 5개를 제공합니다. 학생은 `장면 찾기 → 예상 → 장치 → 빛길 확인 → 관찰 → 설명 → 완료` 순서로 진행합니다. 드래그 없이 거울 방향·위치 또는 렌즈 슬롯을 선택하고, 결과가 다르면 도움말을 읽은 뒤 한 선택을 수정합니다. 최종 화면은 점수 대신 첫 예상, 최종 선택, 시도 수, 관찰, 근거를 보여 줍니다.

## 과학 모형과 안전

- 노란 선은 실제 빛이 아니라 진행 방향을 나타낸 가상 표시입니다.
- 평면거울은 유한 선분의 반사면에서만 반사합니다.
- 볼록렌즈는 평행한 세 가상 광선이 정해진 초점으로 모이는 제한된 장면만 다룹니다.
- 실제 실험은 교사 안내 아래 진행합니다. 강한 빛이나 햇빛을 눈에 비추거나 렌즈로 모으지 않습니다.

이 앱은 실제 광학 실험, 렌즈 공식, 시력 진단, 장치 제작을 대신하지 않습니다.

## 개인정보와 접근성

로그인, 서버 저장, Local Storage, 입력 수집, 외부 런타임 요청을 사용하지 않습니다. 선택은 React 메모리에만 있어 새로고침하면 사라집니다. 모든 핵심 조작은 버튼·라디오 버튼과 키보드로 가능하며 SVG 장면과 같은 순서의 텍스트 경로표를 제공합니다.

## 실행과 검증

```bash
npm install
npm run dev
npm run lint
npm run typecheck
npm test
npm run build
```

자세한 모형·교육과정·수동 접근성 점검은 [docs](docs/)에서 확인할 수 있습니다.

최근 초등 학습자 UX 점검과 브라우저 검증 결과는 [2026-09-02 초등 UX 감사](docs/2026-09-02-elementary-student-ux-audit.md)에서 확인할 수 있습니다.
