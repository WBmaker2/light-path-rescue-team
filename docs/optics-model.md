# 빛길 구조대 광학 모형

## 공통 좌표계

SVG는 `1000 × 600` 고정 좌표계를 사용합니다. 화면 크기가 바뀌어도 내부 계산은 바뀌지 않습니다. 모든 계산은 순수 함수이며 React, DOM, 재생 속도에 의존하지 않습니다.

## 평면거울

거울은 중심점, 길이, `/` 또는 `\` 기울기, 반사면 법선으로 표현한 유한 선분입니다. 광선과 선분의 교차는 광선 앞쪽이며 선분 범위 안에 있을 때만 유효합니다. 반사면 쪽에서 닿은 광선만 다음 식으로 반사합니다.

`r = i - 2(i · n)n`

여기서 `i`와 `n`은 단위 벡터입니다. 반사면 반대쪽에서의 접촉은 학생에게 방향 확인 피드백을 주며 통과시키지 않습니다. 두 거울 미션은 `\` 거울에서 아래로, `/` 거울에서 왼쪽으로 한 번씩 반사되는 검수된 경로를 사용합니다.

## 볼록렌즈

볼록렌즈 미션은 왼쪽에서 오른쪽으로 평행하게 들어오는 위·가운데·아래 세 가상 광선만 다룹니다. 렌즈 슬롯의 위치와 고정 초점 거리로 초점 좌표를 정합니다. 가운데 광선은 광축을 유지하고, 위·아래 광선은 초점을 향합니다. 이는 모든 렌즈·모든 입사 조건의 상 형성 모형이 아닙니다.

## 검증 조건

- 0길이 벡터는 정규화하지 않습니다.
- 교차 뒤 반사 방향은 단위 벡터로 유지합니다.
- 같은 미션·선택은 같은 구간, 이벤트, 종료 상태를 반환합니다.
- 모든 구간 좌표는 유한값입니다.
