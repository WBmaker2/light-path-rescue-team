# 빛길 구조대 초등학생 실사용 점검

- 점검일: 2026-07-18
- 대상: 초등학교 5~6학년 학생
- 환경: 로컬 앱, 데스크톱·태블릿·320px 작은 화면
- 범위: 시작 → 안전 안내 → 안내 활동 → 본 미션 5개 → 관찰 기록 → 다시 시작

## 점검 방법

코드를 먼저 읽지 않고 학생이 보는 화면에서 6개 활동을 직접 끝까지 수행했다. 일부 미션에서는 일부러 틀린 예측과 장치 선택을 한 뒤 수정 흐름을 확인했다. 320px 화면에서는 선택 직후 장면이 보이는지, 터치 목표가 충분한지, 가로 스크롤이 생기는지도 확인했다.

## 잘 된 점

- 점수보다 예상·관찰·수정을 기록해 학습 과정을 강조한다.
- 44px보다 작은 터치 버튼이 없고, 320px에서도 가로 스크롤이 생기지 않는다.
- 본문 글자는 최소 16px이며, 실행 중 콘솔 오류가 없었다.
- 틀린 장치 선택 뒤 장면을 유지한 채 다시 고를 수 있다.
- 직진·반사·굴절을 실제 장면과 연결하는 전체 학습 구조는 적절하다.

## 확인된 문제

### P0. 완료 뒤 다시 시작하면 이전 미션의 결과가 안내 활동에 남는다

결과 화면의 `처음부터 다시 살펴보기`를 누르고 다시 들어가면, 안내 활동에 미션 5의 관찰 문장과 경로 구간이 남았다. 예측과 장치를 고르지 않았는데도 결과 영역이 열려 있었다. 헤더의 `처음부터`는 확인 대화상자를 거쳐 제대로 초기화되므로 두 버튼의 동작이 서로 다르다.

학생 영향: 새로 시작한 활동에서 이전 정답이 섞여 보여 앱을 믿기 어렵고, 안내 활동을 정상적으로 수행할 수 없다.

개선 방향: 두 시작 버튼이 하나의 완전 초기화 함수를 사용하도록 통일하고 회귀 테스트를 추가한다.

### P0. 작은 화면에서 선택 결과 그림이 보이지 않는다

320px 화면에서 장치를 고른 뒤 스크롤 위치를 측정했다.

- `빛길 확인` 직전: 장면 그림의 아래쪽이 화면 위 84px 지점에 있어 그림 전체가 보이지 않았다.
- `빛길 확인` 직후: 스크롤 위치는 거의 그대로였고 장면 그림은 계속 화면 밖에 있었다.

학생 영향: 학생은 선택을 바꿔도 그림이 어떻게 달라졌는지 보지 못하고, 아래쪽 글만 읽게 된다. 이 앱의 핵심인 `선택 → 빛길 관찰` 연결이 끊긴다.

개선 방향: 확인 직후 결과가 반영된 장면으로 이동하고, 장면 아래에 `빛길 기록으로 가기` 동선을 제공한다. 키보드 사용자는 결과 제목에 초점을 받을 수 있어야 한다.

### P0. 마지막 종합 미션의 그림이 선택 전에 정답을 보여 준다

미션 5의 시작 그림에 다음 문구가 이미 표시된다.

- 잠망경: `평면거울 · 반사`
- 돋보기: `볼록렌즈 · 굴절`
- 카메라: `볼록렌즈 · 굴절`

학생 영향: 장치 역할을 생각하고 고르는 활동인데, 보기 전에 정답을 그대로 읽을 수 있어 미션의 학습 기능이 사라진다.

개선 방향: 확인 전에는 `어떤 장치일까요?`처럼 역할을 가리고, 확인 뒤에만 거울·렌즈와 반사·굴절 연결을 보여 준다. 경로 기록도 잠망경 하나가 아니라 세 장치 연결을 모두 보여 준다.

### P1. 근거 안내에 조사 오류와 추상적인 표현이 반복된다

직접 확인한 오류:

- `직진와 관련된 지점`
- `굴절와 관련된 지점`
- `장치 쓰임와 관련된 지점`

학생에게 어려운 표현:

- `검수된 선택지`
- `가상 빛길 작업대`
- `관찰 기록 · 텍스트 경로표`
- `실제 빛길이 멈추거나 바뀐 지점이 수정의 근거예요`
- `세 장치 결합 연결`
- `제한된 가상 모형`

개선 방향: 조사 오류를 문장 단위 데이터로 고치고, 다음처럼 바꾼다.

| 현재 표현 | 학생용 표현 |
| --- | --- |
| 검수된 선택지 | 준비된 보기 |
| 가상 빛길 작업대 | 빛길 그림 |
| 관찰 기록 · 텍스트 경로표 | 빛길 순서 |
| 한 단계씩 | 다음 빛길 보기 |
| 관찰 근거로 설명하기 | 본 것을 바탕으로 설명하기 |
| 세 장치 결합 연결 | 세 장치의 역할 고르기 |

`반사`, `굴절`, `초점`은 교육 목표에 필요한 용어이므로 없애지 않고 짧은 풀이를 붙인다.

- 반사: 거울에서 빛의 방향이 바뀌는 것
- 굴절: 렌즈를 지나며 빛의 방향이 바뀌는 것
- 초점: 빛이 한곳에 모이는 곳

### P1. 장면 도움말이 이름만 반복한다

`광원: 장면에서 찾아봐요`, `표적: 장면에서 찾아봐요`처럼 모든 항목이 같은 문장으로 끝난다.

학생 영향: 무엇을 비교해야 하는지 알려 주지 못한다.

개선 방향: 미션별 관찰 포인트를 구체적으로 제공한다. 예를 들어 직진 미션은 `두 구멍이 같은 높이에 있는지 살펴봐요`, 거울 미션은 `빛이 거울의 어느 면에 닿는지 살펴봐요`로 안내한다.

### P1. 결과 화면이 학습 핵심보다 긴 기록을 먼저 보여 준다

데스크톱 결과 화면은 긴 3열 표로 구성되어 있고, 한 행 안에 예측·최종 선택·시도 횟수·관찰·근거가 이어진다.

학생 영향: 무엇을 배웠는지보다 기록 문장을 해독하는 일이 먼저 된다.

개선 방향: 미션별 카드로 바꾸고 `처음 생각`, `바꾼 선택`, `배운 점` 세 줄만 우선 보여 준다. 교사용 세부 기록은 접어서 볼 수 있게 한다.

### P2. 모바일 헤더에서 학생보다 교사용 기능이 크게 보인다

작은 화면에서 헤더가 두 줄로 늘어나 약 192px를 차지한다. `교사용 활동 안내`가 학생의 현재 단계와 같은 시각적 무게를 가진다.

개선 방향: 모바일에서는 학생 진행 표시를 우선하고, 교사용 안내·안전·업데이트를 짧은 도움말 메뉴로 묶는다. `업데이트 내역`은 메뉴 안에서도 분명히 찾을 수 있어야 한다.

### 최종 실사용 확인

- 320×900 화면에서 시작부터 안내 활동의 결과 확인까지 다시 수행했다.
- 결과 확인 직후 빛길 그림이 초점을 받았고, 핵심 그림·상태·`빛길 기록으로 가기`가 화면에 보였다.
- 320px와 1280px 모두 문서 너비와 화면 너비가 같아 가로 스크롤이 없었다.
- 여섯 활동을 다시 완주하고 결과 카드 5개와 완전 초기화를 확인했다.
- 브라우저 콘솔 오류와 경고는 없었다.
