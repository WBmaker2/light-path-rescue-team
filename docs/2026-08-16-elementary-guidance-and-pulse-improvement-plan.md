# 빛길 구조대 초등학생 풀이 안내·단계 강조 개선 계획

- 작성일: 2026-08-16
- 대상: 초등 5~6학년
- 구현 보완일: 2026-08-17 (정식 원격 반영)

## 목표

학생이 교사의 추가 설명 없이 `장면 찾기 → 예상 → 장치 → 관찰 → 설명 → 완료` 순서를 이해하고, 현재 꼭 해야 할 행동 하나만 찾도록 합니다. 예측과 장치 선택을 한 화면에서 동시에 강조하지 않으며, 오답 뒤에는 실패 원인에 맞는 조건과 `장치 다시 고르기`를 제공합니다.

## 학생 안내

시작과 도움말에는 `이렇게 풀어요`를 보여 줍니다.

1. 그림에서 광원·장치·표적을 찾습니다.
2. 빛이 어떻게 갈지 먼저 예상합니다.
3. 빛길이 이어지도록 거울이나 렌즈를 고릅니다.
4. 노란 선을 처음부터 따라가며 멈춤·꺾임·모임을 관찰합니다.
5. 방금 본 장면과 같은 설명을 고르고 배운 점을 정리합니다.

## 강조와 접근성

- 시작, 안전 확인, 예상 묶음, 장치 묶음, 빛길 확인, 다음 빛길 보기, 설명 묶음, 다음 활동 중 현재 단계의 하나만 `gi-pulse`로 강조합니다.
- 비활성화 버튼과 완료 단계에는 강조를 적용하지 않습니다.
- `prefers-reduced-motion: reduce`에서는 애니메이션을 끄고 정적 외곽선과 `지금 할 일` 표지만 유지합니다.
- 모달이 열리면 배경의 pulse를 중지합니다.
- 모바일에서도 핵심 버튼과 선택지는 44px 이상으로 유지합니다.

## 검증 기준

- 360px·390px·768px·1280px에서 가로 스크롤이 없습니다.
- 키보드로 모든 단계를 진행할 수 있고, 단계 안내가 화면 낭독기에 전달됩니다.
- 안내 활동과 본 미션 5개를 완료할 수 있습니다.
- 자동 테스트, `npm ci`, `npm test`, `npm run build:pages`, `npm run typecheck`를 실행합니다.
