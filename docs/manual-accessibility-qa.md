# 수동 접근성 점검표

- [ ] Tab과 Shift+Tab만으로 예상, 선택, 확인, 근거, 다음 활동을 완주한다.
- [ ] 정보 대화상자가 열리면 닫기 버튼에 포커스가 오고, Tab이 대화상자 밖으로 나가지 않으며 Escape로 닫힌다.
- [ ] 대화상자를 닫으면 원래 트리거로 포커스가 돌아간다.
- [ ] 320px 및 200% 확대에서 가로 스크롤 없이 선택과 텍스트 경로표를 읽는다.
- [ ] 화면 읽기에서 SVG의 제목·설명과 텍스트 경로표가 같은 관찰 결과를 전달한다.
- [ ] `prefers-reduced-motion`에서 경로 확인 뒤 전체 경로가 즉시 표시된다.
- [ ] 색만 보지 않아도 선택, 표적 도착, 차단 상태를 텍스트와 선 모양으로 구별한다.
- [ ] 헤더의 모든 버튼과 라디오 선택지가 44px 이상의 터치 목표를 가진다.
