# Task 3 TDD 보고서

## RED

명령: `npm run test:e2e -- --grep "다시 시작|모바일 관찰" --reporter=line --workers=1`

결과: 두 시나리오가 모두 실패했습니다.

- 결과 화면의 다시 시작 뒤 마지막 미션의 예상과 선택이 남아 `빛길 확인` 버튼이 활성화됐습니다.
- 320px에서 결과를 확인한 뒤 그림 카드가 프로그램 초점을 받지 않았습니다.

## 구현

- `resetSession` 하나로 화면, 미션 번호, 예상, 선택, 첫 선택, 경로, 공개 구간, 확인 횟수, 설명, 피드백, 기록을 모두 초기화했습니다.
- 그림 카드는 `forwardRef`로 포커스를 받고, 모바일 결과 공개 때 동작 줄이기 설정을 존중해 해당 위치로 스크롤합니다.
- 결과 그림에는 `빛길 기록으로 가기` 링크를, 경로표에는 `빛길 순서` 제목과 `#trace-title` 이동 대상을 추가했습니다.
- 브라우저의 소수점 스크롤 정렬로 그림이 `-0.1875px`에 걸치는 문제를 1px 스크롤 여백으로 보정했습니다.
